# 06: Interactive Streamlit Web App ("Digital Wellbeing & GPA Simulator")

**What to build:** A modern, state-of-the-art interactive Streamlit web application (`app.py`) providing a multi-tab experience for exploring dataset trends, testing interactive lifestyle simulations (predicting GPA, stress, and archetype), and inspecting model explainability.

**Blocked by:** 03: Multi-Class Classification Pipeline (Overall Impact), 04: Continuous Regression Models (GPA & Mental Health Index), 05: Behavioral Clustering & Digital Phenotypes

**Status:** done

- [x] Interactive EDA Dashboard: Filters by academic level, primary platform, device, and gender with dynamic charts
- [x] Live Digital Wellbeing & GPA Simulator: User inputs daily usage, bedtime habits, sleep hours, and receives predicted GPA, stress risk, and persona archetype
- [x] Model Explainability & Diagnostics: Interactive SHAP importance charts, confusion matrix visualizer, and cluster 2D projection
- [x] Responsive UI styling with custom themes and KPI stat cards
- [x] Automated integration test validating the app loads without errors
